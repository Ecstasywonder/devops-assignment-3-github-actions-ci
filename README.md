# DevOps Assignment 3 — CI/CD with GitHub Actions

A Bash diagnostic application with automated testing,
Docker packaging, and continuous integration using
GitHub Actions.

## Planned Features

- Linux system information
- Host resolution and connectivity checks
- TCP port connectivity checks
- Automated Bash linting
- Automated application tests
- Docker image builds and smoke tests
- GitHub Actions CI pipeline

## CI Pipeline

validate → test → docker
